COS 201 – Computer Programming I
Week 1: Introduction to Programming and Problem-Solving
In this practical, I created and executed my first Java programme. I learned how to write a Java class, use the main method and display information using output statements.
I also learned that programming helps solve computational problems, supports automation and enables software development.

My goal is to develop simple working applications and improve my programming skills.

COS 201 – Computer Programming I

Week 2: Development Environment and First Java Program
The objective of this practical was to set up the Java development environment and create my first Java programme.

I used the Java Development Kit (JDK), Visual Studio Code, Git and GitHub to practise writing, compiling and executing a Java programme.

I created a file named HelloWorld.java, which displays messages on the screen.

To run the programme, I compiled it using javac HelloWorld.java and executed it using java HelloWorld.
Through this practical, I learned how to create, compile and run a Java programme and submit my work using GitHub.

Week 3: Variables, Data Types, Expressions and Input/Output.
In this practical, I learned how to declare variables, use different data types, perform arithmetic operations and receive input from users using the Scanner class.

I created three Java programmes. The SimpleCalculator.java programme performs addition, subtraction, multiplication and division. The AverageCalculator.java programme calculates the total and average of three students’ scores, while the ItemCost.java programme calculates the total cost of an item using its quantity and unit price.

I also practised displaying formatted results, testing programmes and submitting my work through GitHub.

This practical improved my understanding of Java variables, data types, calculations and input/output operations.
